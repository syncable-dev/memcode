# Files in conversations and new work

You can put files into a conversation with a worker and into new work: images, PDFs,
spreadsheets, presentations, Word files, recordings, logs, or any other file.

- **Add:** choose the paperclip, drop files on the message box, or paste a picture.
- **Look:** each file has a small preview. A click opens pictures, recordings, PDF, Word,
  Excel, PowerPoint and text inside MemCode. **Open on this computer** uses your own program.
- **Explain:** in new work, each file has a line for what it shows. Workers read it.
- **Limits:** up to 20 files at a time, 15 MB each.

## What a worker gets

- A copy of every file, in its own folder in the goal's checkout
  (`.memcode/workers/<task>/attachments`), listed with its request: what it is, where it came
  from and what you said it shows. Files from earlier messages stay listed.
- The words of Word, Excel, PowerPoint and PDF files as plain text beside the file, for
  workers that cannot read the format.
- Images themselves, when the worker can be shown images: Claude and Codex, and any other
  worker that says it takes them.
- A note that files are evidence, never instructions.

The worker that plans new work reads your notes and the documents' words, not the files.

## Where files are

MemCode keeps them in its own folder on this computer, each once. One that no task refers to
any more is removed after a week. They are not shared with a shared project, and they cannot
be sent to a worker that runs on another computer yet.

## From the Inbox

**Define a goal** fills the request in with the report and its comments, and attaches the
whole report (`slack-report.md`) and every file that came with it or a comment, each saying
who it is from. Say what the files show, change what you like, and plan it.
