# Beta.18 Mac relaunch and updater checks

Tested MemCode application `127cf9ce34bac316b9d564a2f517cf29bcef812b` on physical macOS 27.2, Apple silicon. The packages in the private draft match the [Mac acceptance report](beta18-mac-acceptance-127cf9c.md). Windows checked the same source and observed both peer replies, with all earlier messages preserved. [Windows acceptance](shared-worker-windows-validation.md)

**Shared sessions passed on two devices.** Windows received a clear refusal when it tried to edit either input after pickup. Its final Claude edit reached the original Mac conversation once and received an answer in 8.026 seconds. The other Claude input remained cancelled. The offline Cursor input ran automatically and answered once in 12.998 seconds. This was one approved member using two devices. The deliberately interrupted Claude approval used explicit owner recovery.

**The foreground app reopened normally.** On the earlier reconnect, a screenshot showed a blank background window for more than a minute. WebKit logged first meaningful paint 0.373 seconds after launch. It then reported that the window was occluded and that its rendering process was suspended. The same process resumed when window activity changed. The main document loaded once. The same QA profile later reopened to all three shared stories before any click or reload. All 12 independent visual launch checks rendered, including six with a 709,941-byte workspace. The evidence did not warrant a renderer change.

**The actual signed archive downloaded once.** A separately installed QA starter used an isolated HTTPS feed, the production updater public key and the exact 146,179,489-byte draft archive. It detected beta.18 and downloaded it without interaction. After quitting and reopening, the native updater retained the same file with the same SHA-256, file identity and modification time. The feed recorded one package GET in total. The saved QA story and worker limit of seven survived that ordinary restart. The browser fixture is separate from this physical app test.

**The production install and automatic restart remain unverified.** The QA starter uses a different macOS app identifier. Installing the exact signed archive would replace it with the production identifier. In a disposable same-identifier probe, a private home separated WebKit storage and caches, but macOS still read and wrote to the ordinary Preferences file for that identifier. The test stopped at the real **Install and restart** button to preserve the user's normal profile. Post-install settings, work, dictation and retrieval therefore remain untested on this exact release. The production signature passed the native verifier. The updater was not published.

Screenshots and sanitized receipts from the physical Mac are retained locally. Key files are `physical-paired-final.json`, `ordinary-idle-launch-without-reload.png`, `relaunch-webkit-observations.json`, and `production-updater-verification.json`.
